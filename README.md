## Установка

1. Скачайте/скопируйте папку `WordCaptureBot` куда угодно на диск.
2. Установите Tesseract OCR по ссылке выше (если ещё не установлен).
3. Запустите двойным щелчком **`install.bat`**.

   Скрипт сам:
   - создаст изолированное виртуальное окружение (`.venv`) внутри папки;
   - установит все Python-зависимости из `requirements.txt`;
   - создаст на Рабочем столе ярлык **«Word Capture Bot»**;
   - проверит, установлен ли Tesseract, и подскажет, если нет.

Никакие системные файлы и переменные PATH не изменяются — всё нужное лежит внутри папки проекта.

# Word Capture Bot

Открытый (open-source) скрипт на Python для прохождения мини-игры **«Атака Автоматонов»** (typing-мини-игра, где нужно быстро вводить появляющиеся на экране слова — имена героев и предметов).

Скрипт захватывает выбранную область экрана, распознаёт текст через OCR (Tesseract) и автоматически вводит его с клавиатуры, отслеживая, какая часть слова уже введена (по цвету букв), и самообучаясь на новых словах.

Весь исходный код открыт — можно свободно смотреть, менять и распространять.

## Возможности

- Выбор произвольной области экрана мышью (`Ctrl+Shift+R`).
- Старт/стоп по горячим клавишам `F8` / `F9`.
- Ввод целыми фразами, а не по одному слову.
- Адаптивная скорость OCR (снижает нагрузку, если слов много).
- Двухуровневый словарь: встроенный список героев/предметов + самообучение на новых словах.
- Наглядная панель управления со статистикой и логом.

## Требования

- Windows 10/11.
- [Python 3.10+](https://www.python.org/downloads/) (при установке отметьте галочку **Add python.exe to PATH**).
- [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) — отдельная программа, не Python-пакет. Устанавливать в путь по умолчанию:
  `C:\Program Files\Tesseract-OCR\`

## Запуск

Просто дважды щёлкните по ярлыку **«Word Capture Bot»** на Рабочем столе (или запустите `run.bat` из папки).

Откроется панель управления:

1. Нажмите **«Выбрать область»** (или `Ctrl+Shift+R`) и выделите мышью зону экрана, где появляются слова в игре.
2. Нажмите **«Старт»** (или `F8`) перед началом волны/раунда.
3. Нажмите **«Стоп»** (или `F9`), когда мини-игра закончилась.

## Удаление

Запустите **`uninstall.bat`** в папке проекта. Он:

- удалит ярлык с Рабочего стола;
- удалит виртуальное окружение `.venv`;
- спросит, удалить ли файл `learned_words.json` (накопленный самообученный словарь), или оставить его.

После этого папку проекта можно просто удалить вручную — никаких следов в системе не остаётся.

## Файлы проекта

| Файл | Назначение |
|---|---|
| `capture_bot.py` | основной скрипт (захват экрана, OCR, ввод, интерфейс) |
| `requirements.txt` | список Python-зависимостей |
| `learned_words.json` | база самообученных слов (создаётся/пополняется автоматически) |
| `install.bat` | установка окружения и создание ярлыка |
| `run.bat` | запуск бота (используется ярлыком) |
| `uninstall.bat` | удаление окружения, ярлыка и (по желанию) базы слов |

## Отказ от ответственности
